# AS WRITTEN — Atlantis

**쓰인 만큼만.** 아틀란티스에 관한 유일한 기록인 플라톤 『티마이오스』·『크리티아스』의 문장만으로 다시 지은 아틀란티스. 항구에서 포세이돈 신전까지 1인칭으로 걸어 들어가는 웹 체험입니다.

## 경로

```
항구 → 운하 → 다리 ─┬─(↑)→ 신전 앞 광장 → 포세이돈 신전 안
                    ├─(←)→ 바위를 파낸 선착장
                    └─(→)→ 고리 섬 · 경마장
```

## 조작

| 입력 | 동작 |
|---|---|
| `W` / `↑` 누르고 있기 | 앞으로 이동 |
| `S` / `↓` | 뒤로 이동 |
| 마우스 휠 | 앞뒤 이동 |
| 마우스 움직이기 | 둘러보기 |
| 다리에서 `A` / `D` 또는 버튼 | 선착장 / 경마장 갈림길 선택 |
| 휴대폰 | 아래 ▲ ▼ 버튼 누르고 있기 |
| 빛나는 점 | 그 자리를 묘사한 『크리티아스』 원문 보기 |
| 소리 버튼 | 소리 켜기 / 끄기 |

각 장소에 멈추면 원본 장면이 선명하게 표시되고, 그 장면의 근거가 된 원문 문장이 빛나는 점으로 나타납니다. 물결·바람·분수·발소리·신전 안의 울림은 외부 음원 없이 브라우저에서 직접 합성합니다. 항구와 다리에서는 World Labs Marble로 만든 3D 공간으로 이동할 수 있습니다.

## 원문 근거

- 바깥 성벽은 청동, 두 번째 성벽은 주석, 가운데 섬 성벽은 오리칼쿰으로 덮음 (116b–c)
- 섬과 고리 땅에서 캔 흰색·검은색·붉은색 돌, 여러 색을 섞은 건물 (116a–b)
- 바위를 파내 지붕을 얹은 이중 선착장 (116b)
- 은으로 덮은 포세이돈 신전, 금 장식, 상아 천장, 날개 달린 말 여섯 마리가 끄는 전차 위의 황금 신상 (116c–e)
- 고리 섬 위의 경마장 (117c)

## 원문과 다르게 해석한 부분 (고증 메모)

- **신전 외관**: 원문은 "낯설고 이국적인(barbaric) 모습"이라고 적었지만, 장면은 그리스 신전 양식으로 표현됨
- **신전 안 신상**: 원문은 "날개 달린 말 여섯 마리가 끄는 전차 위의 신". 장면 속 큰 날개는 말의 날개를 신상 뒤로 크게 해석한 것
- **항구의 흰 성벽**: 원문상 가장 바깥 성벽은 청동으로 덮여야 함 (운하 장면 끝의 청동 고리가 원문에 가까움)
- **운하 양쪽의 하얀 집**: 원문은 "집들이 빽빽했다"고만 적음. 집의 생김새는 상상으로 채운 부분
- **고리 구조 단순화**: 원문은 바다 고리 3개·땅 고리 2개와 각각의 다리를 말하지만, 체험은 다리 하나로 줄여 가운데 섬에 닿음
- **연대**: 원문은 솔론보다 9,000년 전의 일이라 하지만 삼단노선·청동·운하 같은 세부는 플라톤 당대(기원전 4세기) 그리스의 모습이라는 것이 연구자들의 일반적 해석

## 제작 방식

1. **장면 설계**: 원문에서 구조·재료·규모를 추출해 장소별 이미지를 Midjourney로 생성
2. **이동 연결**: Midjourney 비디오의 시작·끝 프레임 기능으로 장소와 장소 사이를 잇는 1인칭 이동 영상 생성
3. **웹 구현**: 영상 프레임을 키 입력에 맞춰 앞뒤로 재생하는 캔버스 기반 웹페이지 (외부 라이브러리 없음)
4. **3D 공간**: World Labs Marble로 항구·다리를 걸어 다닐 수 있는 3D 월드로 변환
